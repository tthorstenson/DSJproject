## **🎨 design-guidelines.md — *Full Design System***

### **Color Palette**

* Light BG: `#F9F7F1`

* Dark BG: `#1E1E1E`

* Primary Accent: `#005F73`

* Secondary Accent: `#A6A6A6`

* Highlight: `#D4A373`

* Error: `#E63946`, Success: `#2A9D8F`

### **Typography**

* Headings: Georgia, serif

* Body: Inter, sans-serif

* Font sizes: 16px base, scaled headers

* Font weights: 400–700

### **Layout**

* Max content width: 720px

* Padding: 16px base, 32px for wide elements

* Mobile-first stacking

### **Components**

* **Buttons**: Rounded, primary (filled), secondary (outlined), soft hover

* **Inputs**: Large touch targets, auto-expanding textareas

* **Cards**: Use for prompts, entries, quotes; soft shadow, rounded corners

* **Dropdowns**: Minimal UI, close on blur

* **Dark Mode**: Toggle or system-detect

### **Interaction**

* Subtle motion (fade/scale), no jarring animations

* Tap feedback: press effect or glow

* Expandable “More” sections

### **Accessibility**

* Contrast AA compliant

* Keyboard accessible

* ARIA roles for dynamic elements

### **Branding**

* Tone: Stoic, calm, wise

* Optional visuals: nature, columns, sunrises, olive branches
